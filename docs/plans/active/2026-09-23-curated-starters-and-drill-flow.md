# Curated foundations and fluent substitution drills

User direction: require 2–3 authored starter lessons for basic grammar/common
words, with an explicit mark-completed/words-known alternative. Restore roughly
balanced word exposure and one/two lexical changes per quick drill card.

1. Author three frozen sequences: people/roles (は・です), pointing/questions
   (これ・それ・あれ, か), and adjective descriptions using familiar objects.
   Read every Japanese/English card; verify balanced target counts, no unknown
   helpers, no duplicate sentences, and single-change runs with explicit grammar
   boundaries. Explain each new pattern before its drill block.
2. Add starter prerequisite UI and actual-completion tracking. Permit explicit
   known-word declarations without fake encounters, streaks, review cards, or
   spaced-practice credit. Preserve old saved lessons and user history.
3. Make declarations available to later lessons, add completion controls for
   saved materialized lessons, and explain practiced vs declared vocabulary.
4. Replace within-lesson spacing/grammar-variety pressure with balanced selection
   and contiguous substitution runs. Retain cross-lesson SRS, unique sentences,
   explicit pattern boundaries and strict vocabulary gates. Report unavoidable
   coverage limits honestly rather than padding or silently adding words.
5. Exercise completion, skip, save/resume, persistence and fresh-user gating.
   Generate and personally read several post-starter topic drills; export counts,
   transitions and groups. Fix demonstrated defects and run affected/full tests.

No learner progress will be reset or starter lessons marked known on the user's
behalf. UI verification uses previews; practice simulations use isolated tests.
