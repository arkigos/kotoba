# Watercolor assets — 2026-09-13

Created with the built-in `image_gen` tool. Original generated PNGs are retained in the Codex image output directory. Runtime copies live in `public/art/`. Five 5-column × 2-row atlases provide 50 illustrations; the interface uses CSS positioning without modifying the originals. The artwork illustrates meanings and memory aids, not historical glyph shapes. Kanji origins are researched separately in the content dataset.

Prompt:

Wide landscape canvas 5:2 aspect ratio, ideally 2500x1000. Each illustration must be centered in its own cell, surrounded by generous blank pale ivory washi paper; keep painted content within central70% of cell. Absolutely no dividing lines, frames, kanji, letters, numbers, logos, captions or writing anywhere. Clear recognizable subjects, elegant adult illustration, not cartoon or vector icons. Each cell has independent backdrop, no scenery connecting adjacent cells. Consistent size and placement matters for a CSS sprite grid. These represent meanings and memory aids, not historical glyph diagrams. ## Interface paper

Asset: `public/art/watercolor-paper.png`

Prompt:

Use case: stylized-concept. Generate a production background texture for a Japanese language learning app, wide landscape. Very pale warm ivory handmade washi paper with beautiful restrained translucent watercolor pigment washes: sage green near lower left edge, dusty indigo toward upper right edge, faint terracotta near lower right corner. Small authentic sumi ink bleeds, a few dark ink specks confined to far margins, not noisy throughout. At least 75 percent of center is almost blank warm paper with delicate visible fiber and granulation. Editorial, calm, elegant, tactile, Japanese watercolor and calligraphy atmosphere. No text, letters, kanji, figures, objects, symbols, borders, logo or interface. Light overall, so dark interface text remains easily readable. Organic watercolor pooling and feathered irregular edges. This texture will be reused as a faint page background and sampled inside colored buttons.
