# Kotoba

Kotoba is a local-first Japanese sentence drilling app.

The first greenfield slice proves the core loop:

- checked-in curriculum data
- a fast practice player
- local progress
- curriculum validation
- app and practice-flow tests

## Commands

```sh
npm run dev
npm run build
npm run test
npm run test:e2e
npm run validate:curriculum
npm run assets:sync
npm run validate:assets
npm run validate:all
```

The old Create React App plus Express prototype is archived under `archive/`.
