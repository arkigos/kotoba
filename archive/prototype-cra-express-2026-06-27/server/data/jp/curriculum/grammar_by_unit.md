# Kotoba Grammar By Unit

This is the actual grammar course map for frozen Kotoba units.

Each item below is intended to be one long, repetitive unit. A unit may contain a
small bundle of grammar features when they naturally belong to the same mental
move. Vocabulary is still introduced first inside each unit; new grammar appears
after the words have been drilled with older grammar.
