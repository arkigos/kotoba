# Kotoba Japanese Grammar Sequence

This file is an authoring guide for Codex when creating frozen Japanese units.
Each unit should normally introduce one new grammar feature from this list, after
the unit's new words have already been introduced with older grammar.

The order is practical rather than sacred. It is based on common beginner-to-
intermediate Japanese curricula: Tae Kim's basic/essential grammar progression,
JLPT N5-N3 grammar/particle coverage, and standard textbook ordering.

Core authoring rule: grammar is cumulative. Once introduced, it becomes allowed
in all later units.

## Stage 0: Sentence Skeleton

001. A is B: `Aです`
002. Topic marker: `AはBです`
003. Yes/no questions: `Aですか`
004. Answering yes/no: `はい`, `いいえ`
005. Possession/description with `の`: `AのB`
006. Also/too with `も`: `AもBです`
007. Simple negatives: `Aではありません`, `Aじゃありません`
008. Simple past: `Aでした`
009. Past negative: `Aではありませんでした`
010. This/that/that-over-there: `これ`, `それ`, `あれ`
011. Which one: `どれ`, `どのN`
012. This/that noun: `このN`, `そのN`, `あのN`
013. Who/what: `誰`, `何`
014. Sentence ending softener/check: `ね`
015. Sentence ending emphasis: `よ`
