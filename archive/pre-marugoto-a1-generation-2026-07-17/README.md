# Pre-Marugoto A1 Generation Scripts

These scripts are archived reference material from the pre-Marugoto A1 rebuild
path. They generated or patched the earlier A1/foundation unit set before the
current 49-unit Marugoto Starter-inspired A1 source model became canonical.

Do not run these scripts against the active curriculum. Use:

```sh
npm run curriculum:rebuild-a1
```

The active rebuild command runs `scripts/rebuild-marugoto-starter-a1.mjs`, then
syncs word pools and asset manifests.
